# REFLEX local fonts

Inter (variable, 100–900), Space Grotesk (variable, 300–700), and IBM Plex Mono (regular, 400) are served locally as Latin WOFF2 files. No third-party font requests are made when using the studio.

Retrieved from the Google Fonts CSS API on 2026-10-24. Each family's SIL Open Font License is included beside its font file. License sources:

- https://github.com/google/fonts/tree/main/ofl/inter
- https://github.com/google/fonts/tree/main/ofl/spacegrotesk
- https://github.com/google/fonts/tree/main/ofl/ibmplexmono

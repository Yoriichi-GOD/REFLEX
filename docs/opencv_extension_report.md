# Extension technical report

Read STATUS.md for every executed count and open gate; docs/system_architecture.md for the additive design; benchmarks/procedural_safety/public for all 54 actual generated-video runs and failures; benchmarks/anomaly_v2 for the separate real-image study. New software uses OpenCV 5 VideoCapture, perspective warp, HSV segmentation, contours, aspect geometry, quality metrics and actual overlay generation. The bounded policy reads additional existing replay frames, not a new camera view. Observations carry source frame hashes, timestamps, coordinates, model/CV versions and actual evidence references. Temporal support requires unique frames and separated times. Recipe DAG validation, missing evidence and explicit final checkpoints prevent unsupported sequence claims.

The held-out software protocol was fixed before scoring. Inference receives media, recipe, calibration and declared start context; annotations are read only after all predictions are persisted. The same weights/parameters/input hashes/budget caps apply to single/random/agent. Full status confusion, error-type counts, onset and synthetic boundary coverage, false clears and normal false holds are retained. No observed agent accuracy gain. No real procedure, physical-retake, live-UI timing or factory-generalization claim.

Session-owned bearer capabilities, bounded uploads/jobs/frames, safe generated artifact names, header-only authorization, explicit cancellation, immutable input attachment, hash-chained append audit and separate human feedback protect local prototype operation. This is not hardened multitenant video processing; codecs run in process and need isolation before public untrusted media. The original anomaly app and its 143-file freeze remain unchanged. Six real photographs were processed over actual HTTP through the new wrapper with source hashes retained.

Submission video remains unrecorded. The demo script is a plan, not proof of a recorded five-minute video. The required YMCA deck is an authored review artifact with blank team fields; actual upload/receipt remains human work.

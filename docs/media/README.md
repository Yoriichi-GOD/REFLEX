The local JPEG bytes are copied unchanged from the original browser captures. Screen scores are rounded displays; the underlying anomaly distances are not defect probabilities. The curated examples are not a representative accuracy sample. The [study](../../benchmarks/anomaly_v2/README.md) retains missed defects, false alerts and unresolved reviews.

Real photographs use **VisA / Amazon Science, CC BY 4.0**: Yang Zou et al., *SPot-the-Difference Self-Supervised Pre-training for Anomaly Detection and Segmentation*, ECCV 2022. [Publisher source](https://github.com/amazon-science/spot-diff) · [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/). Heatmaps and overlays are derived REFLEX outputs. User-supplied REFLEX artwork remains outside the MIT code grant; fonts retain their OFL notices. See [Third-party notices](../../THIRD_PARTY_NOTICES.md).

Neither image contains customer uploads, credentials, session capability tokens or a private facility photograph. The README's sun emblem reuses the existing project asset at `frontend/assets-ui/reflex-solar-logo.webp`; it is not new branding.

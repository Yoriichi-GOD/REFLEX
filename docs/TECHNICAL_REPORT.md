# REFLEX technical report

## Summary and user

REFLEX is a visual-anomaly triage prototype for an operator comparing a capture with a normal-only profile. It scores the image, marks regions that differ from its fitted normal reference, checks capture quality, and chooses a bounded next OpenCV operation or asks for a new capture. The current deployed profile is a fictional machined plate generated by seeded code. Separate offline profiles were evaluated on two real-image VisA benchmark classes, with poor defect recall. REFLEX has not been evaluated on physical products or MVTec AD.

The user is an inspector or judge who needs an image-derived result, its threshold, a visible region, and a record of why the agent looked again. The main risks are false clears, false alarms from lighting or texture variation, invalid captures, and over-trusting a prototype as a safety device. An operator review remains separate from the model judgment.

## Data, rights, and split

The bundled normal, defect, and mask pixels are generated by `backend/scripts/make_fixtures.py`; they are marked synthetic in `data/assets_manifest.json`. The detector fit uses only 40 generated normal training images. Twelve other generated normal images calibrate the image and pixel thresholds. Evaluation uses 12 disjoint generated normal images and 20 seeded defect images across five fixture changes. Generator seeds and per-asset hashes are recorded in the manifest. Evaluation labels and masks are read only by `backend/scripts/evaluate.py`, after fitting and threshold selection.

No external image dataset or pretrained backbone is bundled. MVTec AD v1 commands use a local copy outside the repository; its official page reports downloads temporarily unavailable. MVTec AD is released under CC BY-NC-SA 4.0 and is non-commercial. Two VisA categories were prepared outside the repository from the official one-class split; the partial archive transfer yielded complete selected categories but no full archive checksum. Per-file image/mask and split-file hashes are recorded. See [`DATA_LICENSES.md`](DATA_LICENSES.md). No MVTec metric is reported for this build.

## OpenCV 5 pipeline

The service checks the installed OpenCV major version at startup and exposes the actual version at `/api/health`. OpenCV decodes the submitted bytes and handles the image operations. Pillow reads only EXIF orientation metadata; orientation transforms use OpenCV. The pipeline converts to Lab and grayscale, measures Laplacian focus and exposure, uses Gaussian smoothing, Sobel magnitude and Laplacian response for the model features, proposes a foreground contour, thresholds and morphologically cleans the anomaly map, maps regions to source-image coordinates, and renders a color heatmap and overlay. `cv2.findTransformECC` performs optional affine registration; unstable or mismatched images are rejected.

## Model and calibration

The current model is `opencv_normal_bank`, an OpenCV-only spatial normal-feature reference. It is not PatchCore. For each fixed feature-grid location, training images produce a median `m` and robust scale `s = max(1.4826 × MAD, channel_floor)`. For feature vector `z`, the local score is:

`A(x,y) = sqrt(mean_c(min(abs((z_c - m_c) / s_c), 30)^2))`.

OpenCV Gaussian smoothing is applied to the map. The image score is its 99.5th percentile. The image threshold is the 95th percentile (higher order statistic) of the 12 normal calibration image scores. The pixel threshold is the 99.5th percentile of calibration-map pixels and is labeled a finite-sample heuristic. The model does not output a probability. Its stored bank and model metadata are hashed.

## Agent action and trace

The deterministic policy first records full-image quality and anomaly evidence. A quality flag selects `request_new_capture`; it does not pass the item. A score below the normal threshold with usable quality returns a qualified pass. A localized score above threshold invokes `inspect_crop` on original source pixels, recomputes normal-bank features, and measures Canny edge density, Laplacian variance, and contrast. A corroborated crop produces `DEFECT_FOUND`; a failed corroboration or unlocalized high score requests human review. The loop currently has one post-initial tool call, below the configured ceiling of three.

Tested traces show a normal fixture with no post-initial call, a scratch fixture with `inspect_crop` and updated crop evidence, and a blurred fixture with `request_new_capture`. The trace contains tool input/output, reason code, timestamps, and evidence IDs. Reviewer actions are stored in a separate table and do not overwrite the model result.

## Evaluation

The current synthetic run has 40 training normals, 12 calibration normals, 12 test normals, and 20 test defects. It measured image AUROC 0.9875, F1 0.923077 at the frozen normal threshold, confusion matrix TP 18 / FP 1 / FN 2 / TN 11, and normal holdout FPR 0.083333. Synthetic pixel AUROC was 0.998488, while pixel IoU was 0.291960 at the frozen normal pixel threshold; the high pixel recall and low precision mean the heatmap is a broad triage cue, not a precise mask.

On the same 32 cases, 19 branched, 13 did not, and agent decisions matched the single-pass threshold decisions. The agent did not reduce the measured errors. Mean added policy time was 1.0477 ms; sequential end-to-end latency was p50 7.075 ms and p95 11.240 ms, with a 131.655 ms maximum. Concurrency was one; memory was not measured. Failure cases and computed overlays are linked in [`EVALUATION.md`](EVALUATION.md).

These numbers describe only this fixture generator and host. They are not MVTec, physical-camera, industrial, or AWS measurements.

### Supplemental real-image VisA benchmark

The model and threshold fit used only normal images from the official train/good split. A deterministic 20% of these normals was held out for calibration; official test labels and masks were read only after the profiles were frozen. Results are for separate offline models and do not change the shipped synthetic profile.

| Class | Fit / calibration normals | Test normals / anomalies | Image AUROC | Precision / recall / F1 | False clears |
|---|---:|---:|---:|---:|---:|
| candle | 720 / 180 | 100 / 100 | 0.7579 | 0.8000 / 0.1600 / 0.2667 | 84 / 100 |
| cashew | 360 / 90 | 50 / 100 | 0.5988 | 0.6250 / 0.0500 / 0.0926 | 95 / 100 |

At the normal-calibrated pixel threshold on the current aspect-preserving maximum-side-256 grid, pixel AUROC/AP/IoU were 0.8591/0.0097/0.0096 for candle and 0.8080/0.1646/0.1883 for cashew. Agent ablations changed no image-level decisions and corrected no image-level errors on either class. This baseline fails a useful defect-recall bar and is not ready for real inspection. Full image and pixel metrics, latency boundaries, robustness, error examples, data provenance, and reproduction steps are in [`../reports/FINAL_BENCHMARK_REPORT.md`](../reports/FINAL_BENCHMARK_REPORT.md).

## Cloud, security, and human control

The service is deployed to AWS in `ap-southeast-2` at the endpoint documented in [`AWS_DEPLOYMENT.md`](AWS_DEPLOYMENT.md). A live synthetic smoke returned OpenCV 5.0.0, `DEFECT_FOUND`, an `inspect_full → inspect_crop` trace, and a generated overlay. Matching CloudWatch request and inspection events were verified for that smoke. A separate 10-warm-up/100-measurement synthetic-only AWS latency profile completed at a 62-second minimum gap to obey the upload guard. Its end-to-end request and server runtime distributions are in the [benchmark report](../reports/FINAL_BENCHMARK_REPORT.md); it is not a saturation or factory-performance test. Exact-window ECS CPU/memory and application-log counts were not captured because the AWS MCP/Console access surfaces were unavailable in this session. The service has no user sign-in and must receive synthetic inputs only. Inspection files use task-local ephemeral storage and are swept on a 24-hour policy; task replacement can remove them earlier. CloudWatch retains structured metadata for seven days but no image bytes or source-image hash. The AWS resource, access, and cost boundary is documented in [`AWS_DEPLOYMENT.md`](AWS_DEPLOYMENT.md) and [`SECURITY_PRIVACY.md`](SECURITY_PRIVACY.md).

Uploads are limited by encoded size and dimensions, the file content type is checked against PNG/JPEG/WebP signatures, decoded dimensions are checked before OpenCV decode, and upload requests have a small per-client rate limit. Local inspections and derived artifacts expire after 30 days by default. The service does not auto-train on uploaded images or reviewer decisions. The optional review endpoint can require a token via `REFLEX_REVIEW_TOKEN`; the local-only default leaves it unset.

## Reproduction and limitations

Run `python backend/scripts/setup.py`, start with `python -m uvicorn app.main:app --app-dir backend --host 127.0.0.1 --port 8000`, then run `python -m pytest -q backend/tests` and `python backend/scripts/evaluate.py`. Details and exact output paths are in [`README.md`](../README.md) and [`EVALUATION.md`](EVALUATION.md).

The current spatially aligned detector is sensitive to changes in view, lighting, normal texture, and crop framing. It produced severe false-clear rates on both VisA classes; two synthetic discoloration cases were also false clears and one synthetic normal was a false defect. The public AWS service still uses only the synthetic profile. Manual polygon ROI editing, deep patch features, physical samples, MVTec execution, S3 inspection persistence, concurrent-load testing, AWS cost measurement, the competition video, public source publication, and Devpost submission are not complete. Docker Compose was not run because the local Docker Desktop engine did not start; the remote CodeBuild image build and API test gate were used for the deployed image.

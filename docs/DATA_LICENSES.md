## VisA 2022-09-22

The [AWS Open Data Registry entry](https://registry.opendata.aws/visa/) identifies the VisA archive as CC BY 4.0 and links to the [Amazon Science spot-diff project](https://github.com/amazon-science/spot-diff) for the dataset description, official one-class split, preparation format, and attribution. The dataset contains real captured images of industrial objects; it is a controlled benchmark, not factory-floor validation.

For the current supplemental benchmark, only the `candle` and `cashew` classes were prepared from the official split; `pcb1` is not present locally. The full archive transfer did not complete, so no full-archive checksum is claimed. The official split index is included at [`../data/visa/1cls.csv`](../data/visa/1cls.csv), SHA256 `a48557e6033318cb90556f706196bc9d247a776a23ea51aecee5a80dd0332995`. Per-case manifests record SHA256 for each selected source image and mask. Raw datasets and fitted banks remain outside the repository in the user-configured external VisA directory; the requested visualization gallery contains small derived comparison panels under `../reports/benchmarks/galleries/`. Preserve the attribution below and identify the material as VisA-derived if redistributing the report/gallery.

Attribution: Yang Zou, Jongheon Jeong, Latha Pemula, Dongqing Zhang, and Onkar Dabeer, “SPot-the-Difference Self-Supervised Pre-training for Anomaly Detection and Segmentation,” ECCV 2022. The official dataset registry identifies the source license as CC BY 4.0.

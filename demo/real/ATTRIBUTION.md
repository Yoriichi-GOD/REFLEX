# VisA real-image demo

Amazon Science; Zou et al., SPot-the-Difference Self-Supervised Pre-training for Anomaly Detection and Segmentation, ECCV 2022.

Source: https://github.com/amazon-science/spot-diff

License: CC BY 4.0 — https://creativecommons.org/licenses/by/4.0/

Original JPEG bytes are preserved. Heatmaps and overlays are generated live by REFLEX. Examples are curated illustrations and include a subtle case the current model misses. No mask or expected decision is supplied to the model.

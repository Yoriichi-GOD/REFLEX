# Procedural safety software suite

`public/` is the public relative-path projection of the immutable measured run. All numeric results, prediction observations/events and actual overlay bytes are retained; original results/source hashes are in PROVENANCE.json. `results.json` is the same public results object exposed by the API. Original media/labels/raw run stay local; regenerate them with backend/scripts/benchmark_safety.py into a new output folder. This is SYNTHETIC SOFTWARE TEST, never physical or industrial performance.

The real-video and external logical benchmark statuses are NOT_RUN. No fake zero or AUROC is supplied. Read all failures and the per-policy counts before interpreting the charts. The 18 generated test clips share one drawing grammar and do not establish industrial generalization. Exact status and specific error finding are separate outcomes.

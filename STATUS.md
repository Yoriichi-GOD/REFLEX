## What runs

`python backend/scripts/dev.py` starts one same-origin service on an OS-selected free loopback port. It prints the actual Inspection Studio and Safety Station URLs. Generated fixture clips are prepared locally when absent. Use `--real` after the pinned-weight download helper to activate the retained real candle/cashew profiles. No unrelated process is stopped.

Safety Station supports consented bounded video upload, selected recipe and manual panel calibration, actual OpenCV 5 decoding/quality/color/contour/geometry analysis, unique-frame temporal confirmation, component/prerequisite checks, timestamped observations and overlays, cancellation, a two-extra-frame single/random/agent comparison, capability-protected artifacts, separate human acknowledgement/refutation, JSON and printable HTML exports. A fresh-view request waits for actual supplied input in a linked child. Camera/still frame APIs exist; a single still remains HOLD because it cannot prove assembly history. No physical machine is connected or controlled.

The original sun/space theme, application script, stylesheet, assets and anomaly service are preserved. One entry link was added outside the original hash-navigation handler. Frozen application and scientific modules were not edited. The new wrapper mounts the legacy application and exposes a separate Safety API/page.
